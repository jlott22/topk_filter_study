# Hardware Pilot Fixtures

This folder preserves imported physical-test inputs. It is not a completed
cross-algorithm result campaign.

- `legacy_clue_trials_g19_c4.csv`: historical 19x19, four-clue trial inputs.
- `legacy_clue_trials_g19_c4_readable.txt`: a human-readable rendering of
  those inputs.
- `handpicked_5_scenario_manifest.json`: the five source scenarios selected
  for the historical hardware handoff.
