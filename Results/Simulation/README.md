# Simulation Results

- `Bayesian/Published/`: canonical completed Bayesian all-K study CSV.
- `Collaborative/Published/`: canonical completed collaborative all-K study CSV.
- `TopKStudyVerification/`: integrity checks for both unified datasets.
- `Bayesian/primary_topk_campaign/`: Bayesian 5%-100% source campaign.
- `TopKLowKSupplement/`: source records used to add lower-K conditions.
- `Sensitivity/`: sensitivity-study source records and reports.
- `Diagnostics/`: diagnostic and smoke outputs.

Use the `Published` CSVs for analysis unless source-level audit detail is
needed.
